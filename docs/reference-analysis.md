# Reference Style：第一组参考要求

收到日期：2026-10-07。暂按用户发送顺序将第一张视为 Before、第二张视为 After；这是视觉需求记录，不是已经标定的处理参数。

## 输入与比较方式

| 图片 | 尺寸 | 备注 |
| --- | --- | --- |
| Before | 768 × 1024 | 私人参考图，不分发 |
| After | 360 × 480 | 私人参考图，不分发 |

两张都是 3:4。比较脸部占比时，应将画布显示为相同尺寸并核对背景、衣领等位置，不能把文件像素尺寸差异视为人脸缩小幅度。本记录依据相对位置进行目视比较，没有完成图像配准、关键点测量或位移场估计。原始附件保持不变。

## 观察与对应要求

| 区域 | 目视观察 / 待验证判断 | 对插件的要求 |
| --- | --- | --- |
| 构图 | 头发、衣领、手及背景的位置总体接近；不支持直接推断整个人头被大幅缩小 | 保持画布和构图稳定；参考对齐后再测量真实脸部占比变化 |
| 鼻部 | After 的鼻翼及鼻尖视觉上更收敛；形变、明暗变化各占多少尚不确定 | 鼻部作为独立的保守控制区；避免把整体瘦脸当作鼻部修正 |
| 脸颊、下半脸 | After 的轮廓看起来略收，下巴附近形状有所变化；需要配准后确认程度 | 局部、平滑、左右协调的轮廓调整；保护脖颈、耳朵和衣领连接 |
| 眼睛、眉毛、嘴巴 | 形状和表情总体接近，没有明显需要默认大眼或改嘴的依据 | 默认不放大眼睛、不改变嘴型；保留原有左右差异和表情 |
| 肤质 | After 看起来更均匀，局部红感和反光有所减弱；低分辨率也会减少可见纹理 | 优化不均匀与局部高光，保留纹理；不能照着低清附件抹掉细节 |
| 色彩 | 两张仍有暖色室内环境感，After 的脸部观感更均匀；精确色差未测量 | 自适应肤色与局部明暗；不写死提白、去黄或全图降饱和参数 |
| 头发、衣服、背景 | 没有需要主动美化或重塑这些区域的依据 | 将其作为几何与肤质处理的保护区域，检查边缘连续性 |

这些是单组图片的视觉判断，尚不能称为多组参考图的共同规律，也不能反推出唯一的相机参数或修图步骤。

## 后续效果验收要求

1. Before、插件输出和 After 采用相同画布显示尺寸，对齐后比较；同时保留原尺寸细节检查。
2. 分别检查鼻部、脸颊、下颌和皮肤，不以整图看起来更小作为通过标准。
3. 眼部与嘴部默认保持原样，鼻部和轮廓变化不得造成表情漂移。
4. 切换处理组可见性时，检查耳边、发际线、下巴到脖颈、衣领和背景边缘是否有牵拉。
5. 肤质效果需在同等有效分辨率下比较；不将缩图或 JPEG 压缩造成的细节损失作为目标。
6. 第二组参考到齐后，再判断哪些变化具有共性并标定保守预设，不从本组目测直接填写固定形变百分比。

## 当前实现与目标的差距

Phase 1 只有以手动脸框为依据的最小局部水平形变。当前尚未实现真实 landmarks 检测、独立鼻部修正、脸颊/下颌约束、保护蒙版、肤质或色调处理，不能据此声称已经复现附件效果。`Reference Style` 仍为管线演示的保守起始值，未根据本组图片重新标定。

2026-10-07 本次只记录参考要求并更新说明，没有修改算法、预设或 Photoshop 文档。
